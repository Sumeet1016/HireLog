🚀 HireLog – Smart Job Application Tracker
HireLog is a smart platform designed to help job seekers efficiently track all their job applications in one place. Instead of juggling multiple spreadsheets, users can monitor application statuses, company details, and important updates through an organized dashboard.

🛠️ Tech Stack
Backend:
☕ Spring Boot

🐘 PostgreSQL / Supabase

Frontend:
⚛️ React

🎨 CSS / Component Library

DevOps & Tools:
🐳 Docker

📦 Maven / npm

✨ Features
🔐 User Authentication – Secure registration and login

📝 Job Posting – Add and manage multiple job applications

📊 Application Dashboard – Track statuses: ✅ Applied, 🗓️ Interview, 🎉 Offer, ❌ Rejected

🔍 Filtering & Sorting – Sort by company, status, or date

📄 Paging – Navigate easily through long application lists

🚀 Future Scope – Notes, tips, and prep materials per company

🚀 Installation & Setup
1️⃣ Clone the Repository
bash
git clone https://github.com/Sumeet1016/HireLog.git
cd HireLog
2️⃣ Backend Setup (Spring Boot)
Ensure PostgreSQL is running locally or use Supabase

Update application.properties with your DB credentials

Run the backend:

bash
./mvnw spring-boot:run
3️⃣ Frontend Setup (React)
bash
cd frontend
npm install
npm start
🌐 App runs at http://localhost:5173

🐳 Docker (Optional)
Build and run with Docker Compose for an isolated environment:

bash
docker-compose up --build
